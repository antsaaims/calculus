Hello, I'm a **function**, usually written $f(x) = y$. Give me an [[Input and Output|input]]
$x$ and I hand back exactly one output $y$ — same input, same output, every time.

**Math example:** if $f(x) = x^2$, then $f(3) = 9$. Ask me for $3$ again and I'll
always say $9$.

**Real-world example:** a vending machine is a function — press B4 (input) and you
always get the same bag of chips (output), never a soda instead.

You'll meet me again as a [[Quantity Function F(x)|quantity function]] $F$ that tracks a
real amount, and as its [[Derivative|derivative]] $f = F'$ that tracks how fast that
amount is changing.
