---
title: Input and Output
description: A function's input goes in, gets processed, and an output comes out — one output for every input.
tags:
  - functions
---

A function is a machine: an **input** goes in, one **output** comes out.

$$
x \; (\text{input}) \;\longrightarrow\; f \;\longrightarrow\; f(x) \; (\text{output})
$$

Every input gets exactly one output — that's what makes it a function and not just any
old relationship between numbers.
